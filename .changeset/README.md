# Changesets

This repository includes Quartz framework source code and Changesets configuration. The configured comparison branch is `main`. There is currently no automated release workflow or npm publication for Computer Science Atlas; do not create a changeset unless a maintainer explicitly asks for a versioned framework release.

The public Atlas website is deployed from `main` through GitHub Pages. Quartz framework documentation is maintained under `docs/`; Atlas learning content lives under `content/`.

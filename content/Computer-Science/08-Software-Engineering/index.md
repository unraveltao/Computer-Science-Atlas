# 软件工程

软件工程（Software Engineering）研究如何协作开发、验证、交付和维护软件，让软件在变化中保持可靠与可理解。

## 代表性知识主题

- 需求分析与规格说明
- 模块化、抽象与代码设计
- 测试策略与质量保障
- 版本控制、评审与协作
- 维护、重构与技术债

## 领域边界

关注软件从需求到维护的工程过程；具体应用领域归入应用开发，运行架构与跨服务设计归入软件架构和分布式系统。

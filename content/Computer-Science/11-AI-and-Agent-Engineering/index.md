# 人工智能与智能体工程

人工智能与智能体工程（AI and Agent Engineering）研究让计算系统完成感知、预测、生成与决策的方法，以及把模型组织为可用智能体系统的工程实践。

## 代表性知识主题

- 搜索、规划与知识表示
- 机器学习与模型评估
- 神经网络与生成式模型
- 提示、工具调用与智能体工作流
- 检索增强、评测与安全

## 领域边界

关注智能方法与智能体（Agent）系统；通用算法基础归入数据结构与算法，智能体面向用户的产品形态归入应用开发。

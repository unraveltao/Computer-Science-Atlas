# 智能体技能工程

> 学习目标不是只写出一个 `SKILL.md`，而是能够针对不同问题，设计、实现、验证和维护真正可用的智能体技能（Agent Skill）。

本专题属于[人工智能与智能体工程](../../index.md)。它使用**不同的工程案例**讲解不同能力，案例之间不必共享同一个 Skill，但遵循一套共同的质量标准。故事用于引出问题，原理与实验才是主线。

## 一个通用的工程质量模型

一个 Skill 的质量至少分为五个独立维度：

1. **发现与触发**：目标客户端是否发现它？适用请求能否触发，不适用请求是否避免误触发？
2. **行为正确**：是否遵从本次用户目标、处理输入不足和输出边界？
3. **执行可靠**：工具、文件、权限、错误与重复操作是否得到妥善处理？
4. **证据充分**：是否有测试记录、预期与实际结果，而不只是助手自称“完成”？
5. **便于维护**：依赖和资源是否清楚，修改后能否重新验证？

每篇文章聚焦一个主要问题，最后将本篇结果映射到这些维度。**文件格式有效不等于行为正确，单次测试成功也不等于完全可靠。**

## 读文章的方式

每篇文章尽量包含：**本篇索引 → 真实问题 → 原理 → 工程实验 → 预测与验证 → 工程思想 → 总结与知识关联**。具体内容按问题需要调整，不强制每篇都有图或脚本。

- 简单流程可以用 Mermaid。
- 需要精细表达分层与关系时使用 SVG。
- 故事插图只有在确实能降低理解难度时再使用。
- 标题和可见链接使用中文；专业术语在正文首次出现时介绍英文原词；源文件名和代码标识符维持英文。

## 使用边界

本专题的 `content/` 是**教学文章**，不是安装到 Agent 的真实 Skills 目录。文中的示例 `SKILL.md` 需要由读者按目标客户端文档放到对应位置，才能测试发现与执行；不要把知识网站里的示例自动当作已经部署的技能。

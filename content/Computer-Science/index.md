# 计算机科学知识地图

以下 14 个领域构成计算机科学知识地图（Computer Science Atlas）的一级导航。知识按其主要学科归属存放；跨领域概念通过内部链接连接，避免重复维护。

| 领域                                                                                | 研究范围                                   |
| ----------------------------------------------------------------------------------- | ------------------------------------------ |
| [数学基础](./00-Mathematical-Foundations/index.md)                                  | 提供描述与分析计算所需的数学工具。         |
| [理论计算机科学](./01-Theoretical-Computer-Science/index.md)                        | 研究计算模型、可计算性与复杂度边界。       |
| [计算机体系结构与组成](./02-Computer-Architecture-and-Organization/index.md)        | 介绍硬件组织、处理器、存储层次与执行机制。 |
| [编程语言](./03-Programming-Languages/index.md)                                     | 探索语言设计、类型、语义、编译器与运行时。 |
| [数据结构与算法](./04-Data-Structures-and-Algorithms/index.md)                      | 组织数据并分析求解问题的方法和效率。       |
| [操作系统](./05-Operating-Systems/index.md)                                         | 理解处理器、内存、文件与设备的系统管理。   |
| [计算机网络](./06-Computer-Networks/index.md)                                       | 学习设备通信、网络协议、寻址与传输。       |
| [数据库与存储](./07-Databases-and-Storage/index.md)                                 | 了解数据建模、查询、事务与持久化。         |
| [软件工程](./08-Software-Engineering/index.md)                                      | 学习软件协作开发、测试、交付与维护。       |
| [软件架构与分布式系统](./09-Software-Architecture-and-Distributed-Systems/index.md) | 研究组件协作、多节点系统与故障处理。       |
| [安全与逆向工程](./10-Security-and-Reverse-Engineering/index.md)                    | 分析系统风险、防护方法与程序行为。         |
| [人工智能与智能体工程](./11-AI-and-Agent-Engineering/index.md)                      | 探索智能方法及其智能体系统工程实践。       |
| [应用开发](./12-Application-Development/index.md)                                   | 面向用户与业务场景构建应用。               |
| [基础设施与运维](./13-Infrastructure-and-Operations/index.md)                       | 关注软件部署、观测、扩展与稳定运行。       |

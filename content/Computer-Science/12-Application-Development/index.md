# 应用开发

应用开发（Application Development）研究面向用户与业务场景构建应用的过程，连接界面、服务、数据和外部平台。

## 代表性知识主题

- Web、桌面与移动应用
- 用户界面与交互
- API 与业务逻辑
- 应用数据模型与集成
- 可访问性、隐私与产品体验

## 领域边界

关注应用功能和用户场景；通用工程流程归入软件工程，底层平台、网络服务和部署归入其他系统领域。

# 编程语言（Programming Languages）

研究语言如何表达计算、如何定义程序含义，以及编译器和运行时如何执行程序。

## 代表性知识主题

- 语法、解析与抽象语法树
- 类型系统与类型检查
- 语言语义与求值模型
- 编译器与解释器
- 内存管理与运行时

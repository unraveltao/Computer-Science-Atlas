# 软件架构与分布式系统

软件架构与分布式系统（Software Architecture and Distributed Systems）研究软件组件如何划分与协作，以及多个节点如何在网络、并发和故障条件下提供服务。

## 代表性知识主题

- 架构风格与系统边界
- 服务通信与 API
- 一致性、复制与分区
- 容错、可用性与弹性
- 事件驱动与消息系统

## 领域边界

关注系统结构和跨节点行为；网络协议细节归入计算机网络，应用本身的业务功能归入应用开发。

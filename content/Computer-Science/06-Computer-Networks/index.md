# 计算机网络

计算机网络（Computer Networks）研究设备如何通过协议交换数据，涵盖网络分层、寻址、路由、传输和应用通信。

## 代表性知识主题

- 分层模型与网络协议
- 以太网、无线网络与链路
- IP 寻址、路由与 DNS
- TCP、UDP 与拥塞控制
- HTTP、TLS 与网络安全

## 领域边界

聚焦通信协议和数据传输；应用层服务设计归入应用开发，跨节点状态与故障处理归入分布式系统。

# 数据结构与算法

数据结构与算法（Data Structures and Algorithms）研究数据的组织方式与解决计算问题的步骤，并分析正确性、效率和资源开销。

## 代表性知识主题

- 数组、链表、栈与队列
- 树、图与索引结构
- 排序、搜索与哈希
- 图算法与路径问题
- 复杂度分析、贪心与动态规划

## 领域边界

关注问题求解方法及其复杂度；数学证明工具归入数学基础，具体计算模型的边界归入理论计算机科学。

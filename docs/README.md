# Documentation in this repository

This repository contains two kinds of documentation:

- **Computer Science Atlas content** lives in [`content/`](../content/) and is published as the website. It follows the project content and asset conventions.
- **Quartz framework documentation** lives in this directory. These guides explain the upstream static-site generator used to build the Atlas; they are not Atlas learning articles and are not the source directory for the published site.

The site build reads `content/` by default. Use the Quartz guides when you need to understand or configure the framework. Repository-specific content and asset conventions are documented in the root [`AGENTS.md`](../AGENTS.md).

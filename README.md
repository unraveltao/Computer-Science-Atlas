# 计算机科学知识地图

[![在线阅读：计算机科学知识地图](https://img.shields.io/badge/在线阅读-Computer%20Science%20Atlas-284b63)](https://unraveltao.github.io/Computer-Science-Atlas/)

Computer Science Atlas（计算机科学知识地图）是一个持续建设的开放式计算机科学知识项目。我们按照学科领域组织知识，通过原理解释、代码实例、可视化图示和跨领域链接，帮助学习者建立系统、相互关联的计算机知识体系。

## 项目目标

- 以学科领域整理计算机科学知识，而不是按工具或编程语言分类。
- 让概念页面可以独立阅读，也能通过链接互相连接。
- 从学习与实践中持续提炼可复用的公开知识。

## 如何访问

打开[在线知识地图](https://unraveltao.github.io/Computer-Science-Atlas/)，从首页进入领域导航选择主题，再通过内部链接、搜索和关系图继续探索。

## 内容原则与参与

本站以中文为主，保留常用 English technical terms。领域首页介绍研究范围和代表性主题；知识文章会在经过整理后逐步补充。当前 V0.2 提供导航与内容规范，不代表所有领域主题都已有完整文章。项目使用 Quartz 作为静态站点生成器；学习内容位于 `content/`，框架使用说明位于 [`docs/README.md`](docs/README.md)。

欢迎通过 [GitHub Issues](https://github.com/unraveltao/Computer-Science-Atlas/issues) 提交纠错、建议或贡献想法。开始贡献前请阅读[参与贡献](CONTRIBUTING.md)；内容分类、写作和图片规范见 [`docs/README.md`](docs/README.md)。
